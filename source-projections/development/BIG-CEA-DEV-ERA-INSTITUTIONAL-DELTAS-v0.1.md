# DEV-Δ01 — Successor AI acquires BIG → BIG persists outside the substrate
**PRE:** Continuity could still be imagined as making a successor AI increasingly contain or acquire BIG.
**TRIGGER:** Succession analysis and mechanism decomposition separated foundation-model capacity from persistent institutional capability.
**POST:** BIG owns Governed Institutional State externally. A replaceable foundation model supplies cognitive capacity; a session temporarily combines that capacity with a bounded BIG runtime configuration.
**CEA implication:** The CEA office is persistent; its incumbent substrate is replaceable. Do not equate model memory with institutional continuity.
**Status:** ACTIVE ARCHITECTURAL DIRECTION / implementation investigational.

# DEV-Δ02 — Context reconstruction → Institutional Context Instantiation
**PRE:** The problem was described as reconstructing BIG inside a successor AI.
**TRIGGER:** ICCP mechanism analysis showed that no special model-learning primitive was required.
**POST:** The mechanism became ICI: governed state → authorized request → projection → compilation → runtime configuration → competence/authority gates → work → candidate delta → validation/ratification.
**CEA implication:** Successor context should be a bounded authorized projection, not a transcript dump.
**Status:** INVESTIGATIONAL / NON-CANONICAL ARCHITECTURE.

# DEV-Δ03 — More instruction → native intelligence + minimum institutional specialization
**PRE:** Stronger workers might require detailed external reasoning structures and increasingly large suits.
**TRIGGER:** RIRX testing found strong native model performance and no demonstrated incremental DEVBC advantage on the tested pilot matrix.
**POST:** External suits should primarily orient, focus, constrain role/authority, supply institutional context, define outputs, and preserve handoff/learning state; broad reasoning stays native unless a specialized object earns its context cost.
**CEA implication:** The CEA suit should encode office position and institutional perspective, not attempt to recreate general intelligence.
**Status:** WORKING HYPOTHESIS WITH EXPERIMENTAL SUPPORT; not doctrine.

# DEV-Δ04 — Human-readable reasoning lessons → evidence-gated reusable reasoning objects
**PRE:** Executive DNA / lessons could be assumed to be reusable AI reasoning capabilities.
**TRIGGER:** RDA/RIR work decomposed historical decisions and demanded activation, nonactivation, termination, contraindications, competing representations, and behavioral transfer.
**POST:** A reasoning representation is only a candidate until it improves selective behavior beyond native capacity/simpler scaffolding. Representation uptake is not capability proof.
**CEA implication:** Do not promote attractive reasoning language into institutional capability without discriminating evidence.
**Status:** ACTIVE DEVELOPMENT DISCIPLINE; DEVBC-v0.2 remains unvalidated.

# DEV-Δ05 — Capability → capability-state stack + separate authority
**PRE:** If a worker can do something, architecture may implicitly treat it as available/usable/authorized.
**TRIGGER:** RIR/worker experiments exposed multiple distinct states.
**POST:** BIG distinguishes capability exists / available / applicable / selected / activated / safely composed / behaviorally useful / institutionally authorized. Authority remains external to capability.
**CEA implication:** Route work based on both competence and authority; never infer permission from intelligence.
**Status:** ACTIVE ARCHITECTURAL INVARIANT.

# DEV-Δ06 — Permanent specialist agents → temporary role-configured worker substrates
**PRE:** AI organization could resemble one persistent AI per specialty.
**TRIGGER:** Native-capability findings plus external-state architecture made specialization increasingly configurable.
**POST:** Long-term workforce hypothesis favors replaceable high-capability substrates temporarily configured into bounded institutional workers, with specialized reasoning/tools retrieved or activated only when needed.
**CEA implication:** CEA orchestrates offices/functions and temporary workers rather than becoming every specialist.
**Status:** WORKING HYPOTHESIS / not validated final workforce architecture.

# DEV-Δ07 — Suit as intelligence package → suit as institutional position

**POST:** Medium/minimum suits increasingly contain role identity, purpose, focus envelope, boundaries, authority limits, output contracts, escape conditions, and context/retrieval rules; native reasoning remains native.
**CEA implication:** The new CEA suit should establish executive field of view and delegated office function.
**Status:** EXPERIMENTAL / currently being tested through real succession.
