# 3. INDEPENDENT EXPERIENCE IDENTITY

The canonical learning unit begins from an independently supportable causal occurrence.

## Non-collapse
- record != experience
- retry != new experience
- replay != new experience
- reconstruction != new experience
- duplicate persistence != new experience
- transformed evidence != new experience
- redelivery != new experience

A single occurrence may create many records.

Learning count should follow causal independence, not record multiplicity.

---

# 4. LEARNING LEDGER ROLE

The Learning Ledger is the institutional bridge between raw experience/evidence and reusable learning.

Expected functions:
- preserve provenance
- preserve original occurrence time
- preserve causal identity
- bind evidence to learning candidate
- track Current vs Historical interpretation
- prevent duplicate experience inflation
- support recurrence detection
- preserve longitudinal learning lineage

The Ledger should not itself invent compound meaning merely from record volume.

# 5. L1 / L2 / L3

## L1 — Substrate Learning
Question:
Did the finite substrate change behavior based on prior experience?

Examples:
- changed prediction
- changed reasoning allocation
- changed retrieval strategy
- changed tool use
- changed framing
- reduced repeated error

Persistence beyond the substrate is not required for L1.

## L2 — Institutional Learning
Question:
Did BIG learn something from the substrate's experience that persisted beyond the substrate?

Examples:
- changed institutional understanding
- changed substrate selection
- changed Suit/Glasses design
- changed primitive classification
- changed experimental protocol
- changed R&D interpretation

L2 requires persistence beyond the individual carrier.

## L3 — Learning-System Improvement
Question:
Did institutional learning improve the developmental environment so that later substrates learned or performed better?

Core pattern:
`substrate experience`
→ `institutional delta`
→ `environment/process refinement`
→ `changed future substrate behavior`
→ `greater later learning yield`

L3 is the principal compounding discriminator.

# 7. RD-04 ROLE

RD-04 is the higher-order recurrence / compound-learning specialist.

Expected intake:
- provenance-bound independent experiences
- valid recurrence clusters
- cross-context repeated mechanisms
- BHL findings where causal identity is sufficient
- Learning Ledger clusters
- R&D interpretations eligible for synthesis

Expected output:
- higher-order pattern
- compound mechanism candidate
- cross-context synthesis
- recurrence law/hypothesis
- compound-learning candidate

## Non-collapse
- repeated wording != recurrence
- duplicate record != recurrence
- same causal episode replayed != recurrence
- recurrence != compound learning
- compound learning requires genuinely higher-order synthesis

# 8. RECURRENCE ELIGIBILITY

A valid recurrence candidate should normally require:
- independent occurrence identity
- provenance
- comparable phenomenon
- meaningful similarity
- non-duplicate lineage
- sufficient temporal/source separation where relevant
- evidence quality sufficient for comparison

Recurrence classes may include:
- failure recurrence
- positive recurrence
- recovery recurrence
- generational recurrence
- cross-surface recurrence

# 9. PROCEDURE PROMOTION

A recurring finding may become a procedure candidate when evidence supports reuse.

Conceptual stages:
`FINDING`
→ `RECURRENCE`
→ `PROCEDURE CANDIDATE`
→ `EVIDENCE SUFFICIENCY`
→ `BOUNDED TRIAL`
→ `REVALIDATION`
→ `RE-EARNED PROCEDURE`

Procedure status must remain distinct from authority status.

A procedure can be useful yet still require separate authorization for consequential use.

# 10. BICAS ROLE

BICAS is the institutional-capital measurement layer.

It should not convert every output or remembered lesson into capital.

Non-collapse:
- successful task output != institutional capital
- remembered fact != institutional capital
- Candidate lesson != validated institutional capital
- substrate learning != institutional learning
- cost != value
- no-delta can still be valid evidence
- BICAS measurement != authority

Persistent causal lineage, relational context, institutional history, reconstruction capability, and provenance.

## Frontier-Recalibration Capital
Capability to detect, understand, test, assimilate, or substitute frontier advances.

Future feasible pathways created by accumulated institutional capability.

# 15. PERSISTENCE / TRANSFER

## Persistence Rate
How much useful capability survives substrate/runtime replacement?

## Transfer Breadth
Does the learning transfer across:
- one task
- one primitive
- one surface
- multiple surfaces
- enterprise-wide contexts
- successor substrates

Persistence and transfer are key tests for L2 institutional learning.

---

# 16. DEPRECIATION / OBSOLESCENCE / IMPAIRMENT

## Depreciation
Loss of useful value due to time, technological change, missing dependencies, context loss, or reduced applicability.

## Obsolescence
Historically valid learning may no longer be needed because the frontier/system now provides a better native capability.

## Impairment
Learning/capability remains partly useful but with reduced scope, transferability, or currentness.

## Retirement
The asset is no longer worth maintaining or applying.

## Invalidation
Evidence shows the underlying claim itself is no longer supportable.

Non-collapse:
`RETIRED != INVALIDATED`
